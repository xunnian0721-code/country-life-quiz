# 你适合去哪个国家生活？

一个无需服务器的中文网页小游戏。页面、样式、题目和计分逻辑都在 `index.html` 中。

## 在线访问

GitHub Pages：https://xunnian0721-code.github.io/country-life-quiz/

原 Netlify 网址：https://dazzling-biscotti-acb3fb.netlify.app/

## 本地运行

双击 `index.html`，用浏览器打开即可。

## 更新 GitHub Pages

1. 修改并保存 `index.html`。
2. 打开 GitHub 仓库 `xunnian0721-code/country-life-quiz`，上传修改后的 `index.html` 并提交。
3. 等待 GitHub Pages 发布完成，再打开上面的 GitHub Pages 网址检查。

修改本地文件不会自动更新线上页面，必须把修改提交到 GitHub 仓库。
